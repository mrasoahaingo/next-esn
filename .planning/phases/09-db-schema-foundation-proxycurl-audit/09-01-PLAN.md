## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Serveur Next.js (service role) → Postgres | La service role contourne la RLS : l'isolation repose sur `.eq('org_id', orgId)` côté code et sur les FK composites côté schéma |
| Clé anon / futur JWT Clerk → PostgREST | Non utilisé aujourd'hui ; la RLS est la défense en profondeur |
| Collecteurs externes (phases 10–13) → tables | Données non fiables écrites dans `payload`, `source_results`, `score_breakdown`, contacts |
